# TravelMate

TravelMate is a full-stack travel planning application built with Next.js and TypeScript.

## Features

- Email and Google authentication
- AI travel assistant
- Trip creation and management
- Destination search
- Interactive maps and routes
- Weather information
- Travel budget estimation
- Accommodation information
- Travel buddy discovery
- Responsive mobile and desktop UI

## Tech Stack

- Next.js
- React
- TypeScript
- PostgreSQL
- Prisma
- Google OAuth
- Resend
- Leaflet
- Travel APIs
